# 미사일 커맨드 : 어휘 방어전

떨어지는 영단어를 요격하며 외우는 로그라이크. 브라우저에서 바로 돌아간다.

화면 아래에 뜻이 뜨고, 위에서 그 뜻에 맞는 단어와 헷갈리는 오답들이 함께 내려온다.
맞는 것만 골라 요격하면 되고, 놓치면 기억 저장소가 하나 무너진다.
웨이브가 올라갈수록 빨라지고 오답이 늘고 여러 문제가 겹쳐서 떨어진다.

핵심은 이거다 — **놓친 단어는 반드시 다시 온다.** 이번 판 안에서 두세 문제 뒤에,
그리고 며칠 뒤에. 그 일정을 Anki가 쓰는 것과 같은 **FSRS-5** 알고리즘이 계산한다.

```bash
npm start      # http://localhost:5173
npm test       # 단위 테스트 86개
npm run check  # 계층 경계 · 서비스 워커 · 자산 정합성
```

설치할 의존성은 없다. Node 18+ 만 있으면 된다.
(`index.html`을 파일로 바로 열어도 동작하지만, 오프라인 캐시는 서버로 열어야 켜진다.)

## 어떻게 외워지는가

게임의 재미와 학습 효과가 따로 놀면 둘 다 실패한다. 그래서 게임 규칙 자체를
인지과학이 말하는 "기억에 남는 조건"과 겹쳐 놓았다.

**인출 연습 (retrieval practice).**
보기를 다시 읽는 것보다 스스로 꺼내는 쪽이 훨씬 강하게 남는다.
그래서 기본 출제 방향이 `뜻 → 영단어`다. 보고 알아보는 게 아니라 꺼내게 만든다.

**간격 반복 (spaced repetition), FSRS-5.**
단어마다 안정성 `S`(며칠 버티는가)와 난이도 `D`를 추적하고,
망각곡선 `R(t) = (1 + 19/81 · t/S)^-0.5` 위에서 회상 확률이 목표치(기본 90%)로
떨어지는 시점에 다시 낸다. 너무 일찍 복습하면 시간 낭비고 너무 늦으면 잊는다.
Anki 23.10+ 의 기본 스케줄러와 같은 수식이고, 기본 파라미터 19개도 동일하다.

**간격 효과 (spacing effect).**
잊기 직전에 힘들게 떠올린 기억이 가장 크게 강화된다.
FSRS가 이걸 수식으로 갖고 있어서, 오래 기다렸다 맞힌 단어일수록 다음 간격이 크게 벌어진다.

**변별 학습 (discrimination learning).**
오답을 무작위로 뽑으면 대충 훑고 찍게 된다. 그래서 같은 품사, 같은 주제,
비슷한 철자, 그리고 **이미 자주 틀린 단어**에서 오답을 고른다.
진짜로 헷갈리는 것끼리 붙여 놔야 구별이 는다.

**즉시 재출제 (learning steps).**
틀린 단어는 판을 넘기지 않는다. 2~3문제 뒤에 반드시 다시 나온다.
장기 일정(며칠 뒤)과 단기 단계(이번 판 안에)를 따로 굴리는 건 Anki와 같은 구조다.

**인출 유창성 (retrieval fluency).**
얼마나 빨리 맞혔는지로 `다시 / 어려움 / 보통 / 쉬움`이 자동으로 매겨진다.
버튼을 눌러 자기 평가할 필요가 없다 — 이미 손이 답했다.

### 한 가지 일부러 보수적으로 잡은 것

FSRS의 기본 파라미터는 Anki 사용자가 **자유 회상**을 스스로 채점한 데이터로 맞춰져 있다.
그런데 이 게임은 **4지선다 재인**이다. 보기 중에 답이 있으면 실제 기억보다
"알 것 같은" 느낌이 부풀려지고, 그대로 먹이면 복습 간격이 실제 망각보다 길어진다.

그래서 두 가지 제동을 걸어 두었다.

- 보기가 4개 미만이면 `쉬움`을 주지 않는다 (찍어서 맞을 확률이 너무 높다).
- 그 단어를 **처음 만난 판**에서는 `쉬움`을 주지 않는다. 한 번 알아봤다고 2주 뒤로
  미루는 건 과신이다. 정말 아는 단어면 며칠 뒤 한 번 더 맞히고 그때 크게 멀어진다.

### 유물은 학습 데이터를 건드리지 않는다

로그라이크 보상은 점수·속도·탄약·연출만 바꾼다.
**어떤 유물도 FSRS의 S/D 계산에 손대지 않는다.**
보상으로 안정성을 부풀리면 복습 일정이 거짓말을 하게 되고, 그건 이 게임이
존재하는 이유를 스스로 무너뜨리는 일이다. 학습에 관여하는 유물은
"무엇을 더 자주 보여줄까"(출제 구성)까지만 건드린다.

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 클릭 | 그 지점으로 요격. 십자선의 원이 폭발 범위다. |
| 숫자키 `1`–`9` | 현재 문제의 왼쪽부터 N번째 미사일을 조준. 키보드만으로 완주 가능. |
| `Q` `W` `E` `R` | 스킬 발동 (집중 게이지 소모). |
| `ESC` / `P` | 일시정지. |

조준은 **예측 조준**이다. 미사일을 클릭하면 요격탄이 도착할 시점의 위치를 계산해
쏜다. 비행시간·폭발 반경·탄약 제한은 그대로 두되, 빗나가는 이유가
"리드샷을 못 했다"가 아니라 **"단어를 잘못 골랐다"** 뿐이게 만들기 위해서다.

## 로그라이크 시스템

- **기억 저장소 6개** = 체력. 정답을 놓치면 하나씩 무너진다. (오답이 착탄하는 건 무해하다.)
- **콤보** — 연속 정답마다 배수가 오르고 집중 게이지가 찬다.
- **집중** — 스킬 자원. 시간 왜곡 · EMP 정화 · 자동 조준 · 긴급 복구 · 과부하 · 기억 소환.
- **유물 20종** — 확장 탄두, 정밀 신관, 연쇄 반응, 기억의 방패, 복리 이자, 망각곡선 역이용 등.
- **저주 4종** — 5웨이브마다 나오는 *악마의 거래*로만 등장. 대가를 치르고 희귀 유물 2개를 한 번에.
- **다탄두 · 장갑 미사일** — 후반 웨이브에서 분열하거나 두 번 맞혀야 터진다.
- **시드 고정** — 같은 시드면 같은 웨이브 구성. 기록 비교와 재현이 가능하다.

## 덱

내장 덱 3개, 합계 **721단어**.

| 덱 | 단어 수 | 내용 |
|---|---|---|
| 기초 필수 | 324 | 일상 고빈도 기본 어휘 |
| 수능·학술 핵심 | 278 | 수능·모의고사·학술 지문의 추상 어휘 |
| 비즈니스 · TOEIC | 119 | 사무·무역·회계 실무 어휘 |

**내 단어장**은 `덱 관리`에서 CSV·TSV를 그대로 붙여 넣으면 된다.

```
apple, 사과
bread, 빵, n, food
```

3번째 칸(품사)과 4번째 칸(태그)은 선택이지만, 넣어 두면 오답 선택이 훨씬 정교해진다.

## 데이터

복습 기록은 브라우저 `localStorage`에만 저장된다. 서버로 아무것도 보내지 않는다.
기기를 옮기려면 `설정 → 내보내기`로 JSON을 받고 다른 기기에서 가져오면 된다.
가져오기는 **병합**이 기본이라, 두 기기에서 각각 진행했어도 더 많이 복습한 쪽이 남는다.
